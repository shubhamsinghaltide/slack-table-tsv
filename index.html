Slack Table Maker

Build or paste a table, then copy it as TSV (or a rich table) to paste into Slack.

1 · Table

Tip: click any cell and paste data copied from Excel / Google Sheets / a TSV or CSV — it fills the grid automatically. JSON works too: an array of objects (keys become the header) or an array of arrays. Tab / Enter move between cells.

2 · Output

Copy TSV: plain tab-separated text. Rich table: puts an HTML table on the clipboard so Slack (canvas/messages that support tables) renders a real table. Aligned: monospaced, space-padded text inside triple backticks — works in any Slack message.
